# Roughcut — Phase 1 Task Board

Statuses: `ready` (deps met, can start) · `blocked(<dep>)` · `in-progress` · `done` ·
`DECISION` (needs Karl's input before work can start).

Rules (enforced by [../CLAUDE.md](../CLAUDE.md)):
- A task is **done only when every DoD item passes with fresh command output** in the session
  that closes it. No "done by inspection".
- Closing a task = DoD green → update status here → CHANGELOG entry → one commit.
- DoD items marked `[R#]` use a threshold owned by a research study; until that study is done,
  use the provisional value shown and flag the task `done*` (provisional) — re-verify when the
  study lands.

## T1 — Media probe → manifest — `blocked(T0)`
ffprobe wrapper producing `media` rows incl. VFR flag and log-profile detection.
**DoD:**
- [ ] Test fixtures: ≥4 synthetic files generated by ffmpeg in-test (CFR 23.976/25/60, one VFR, one with rotated metadata)

## T2 — Proxy generation — `blocked(T1)`
540p CFR proxies with source↔proxy frame mapping.
**DoD:**

- [ ] VFR fixture: proxy is CFR and audio drift < 1 frame over a 10-min synthetic VFR test clip
- [ ] Frame-mapping function round-trips: source frame → proxy frame → source frame identity on fixtures
- [ ] Re-running skips existing up-to-date proxies (idempotent; mtime+hash check tested)

**DoD:**

- [ ] Keyframes (first/middle/last) extracted per shot into `artifacts/`, paths recorded
- [ ] `roughcut ingest shots <project>` idempotent

## T5 — Cheap signals + gate — `blocked(T3, T4)`

## T10 — Assembly render — `blocked(T9, R5)`
